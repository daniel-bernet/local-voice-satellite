# Images

Photos of the built V2 satellite. They're added after the build is documented, with EXIF/GPS metadata stripped and resized to a maximum of 1600 px. Until then the docs show renders of the CAD model in three places, and the other photo spots are marked with a `PHOTO NEEDED` comment in the Markdown source.
